# Fake-Product-Detector-1-
A Java-based application developed to detect and verify fake products using product information, verification codes, and QR codes.

## Technologies Used

- Java
- Java Swing
- Maven
- PostgreSQL
- JDBC
- QR Code

## Features

- Product registration
- Product verification
- QR code generation
- QR code scanning
- Genuine/Fake product detection
- Verification history
- Admin management
